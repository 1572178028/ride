自驾带车、说明停车费用与条件、换上自行车看风景。静态网站无需安装依赖，支持 GitHub Pages 项目路径。

当前有 **11 条主线、16 种方案、8 个片区、8 处去重停车片区（5 处免费条件、3 处收费参考）、22 家去重餐饮咖啡茶饮店、18 处去重休息地点/建议**。这些数量不把长短线重复算作新区域，也不把同一家咖啡店在不同路线上的出现重复计数。

## 运行与检查

```sh
cd /path/to/ride
python3 -m http.server 3000 --bind 0.0.0.0
```

打开浏览器访问本地3000端口。运行和浏览不需要在线地图API；点击导航、来源链接需要联网。收藏保存在当前浏览器。

```sh
node tests/catalog.test.cjs
python3 tests/browser-check.py
```

Node检查覆盖：统计去重、停车条件、坐标转换、来源字段、路线连续性、里程、真实OSM道路边及单行方向。浏览器检查需要Python Playwright及Chromium，覆盖桌面和手机布局、筛选、长短线、标记、导航参数与收藏。

重建新增区域地图与导出图片：

```sh
python3 scripts/build-regional-maps.py
python3 scripts/build-verified-maps.py
node scripts/generate-maps.cjs
python3 scripts/export-maps.py
```

SVG生成器不需要浏览器。Python图片导出需要Playwright与Chromium；另有 `node scripts/export-maps.cjs` 离线导出，需要可用的sharp包（可通过NODE_PATH指向已有运行时）。网站本身不依赖这些开发工具。道路快照保存在`research/`，来源、证据强度和限制见[data-notes.md](data-notes.md)。

## 地图与导航

橙色为主线，绿色叠线是当前规划实际经过的路网骑行道；绿色不代表自行车独享或全程隔离。往返环路显示去回方向，原路往返只画去程、里程计双程。地点编号对应补给卡片，拥挤标记有细引线，地图可放大、定位、保存PNG。

底图及路线采用WGS84，向高德、百度传坐标时转为GCJ-02。精确道路起点支持高德与百度骑行导航；停车入口或店门未精确确认的片区，采用完整场所名称检索/名称导航，并说明其定位范围。停车片区P和道路起点S可能分开，不用直线假装已经核查过的接驳道路。

免费条件适用于标为“免费”的方案：不把短时免停、消费抵扣、住店权益或节庆临时政策算作常态免费。收费方案另外显示规则、参考价格与证据状态。公开资料不是到访当天的现场确认；免费方案发现收费或消费门槛时就不成立；收费方案现价与停车取车窗口按入口公示，关闭车场不可使用。停车原文发布日期与此次来源读取日分别展示。

## GitHub Pages

仓库管理员在仓库Settings → Pages选择从`main`分支根目录发布。`.nojekyll`保留静态资源路径，推送后按GitHub实际部署状态确认上线。本次工作区修改不自动等于已推送或已上线。

## 文件

`catalog.js`：原始路线；`planning-data.js`：原有里程变体；`regional-catalog.js`：新增区域、补给、证据和统计；`map-data.js`与`regional-map-data.js`：本地道路、水域及路径；`map-renderer.js`：网页及导出共用地图渲染；`app.js`：交互与导航；`huzhou-research.js`：原湖州调研方向；`verified-catalog.js`：本批收费方案、剩余候选更新和最终统计；`verified-map-data.js`：本批真实道路与分段元数据；`maps/`：所有方案SVG、PNG及独立西湖研究图。

地图数据 © OpenStreetMap contributors，ODbL。路线为公开路网规划，非实骑轨迹；未承诺当天道路开放、店铺营业及服务设施可用。

## 按区域扩充路线的 Skill

项目内置 [`expand-cycling-routes`](.agents/skills/expand-cycling-routes/SKILL.md)。在以本仓库为工作目录的 Codex 中可这样使用：

```text
$expand-cycling-routes 帮我尽可能补充安吉的骑行线路，并更新到这个项目。
```

也可以说“使用项目里的骑行线路扩充 skill，补充太湖东岸”。若当前客户端未自动发现项目技能，可明确让它读取上面的 `SKILL.md` 后执行。

只需提供区域；技能负责调研免费停车依据、规划真实道路路线、区分专用道与共用道路、补充餐饮咖啡和休息点、生成地图及百度/高德导航，再完成项目接入与验证。默认免费停车，用户明确允许时可收录收费方案并单独标注；停车定位、道路准入或几何仍不足的方向进入待核查区，不靠复制长短版或虚构地点增加数量。技能文件会随仓库一起保存；推送、发布沿用当次会话授权。
