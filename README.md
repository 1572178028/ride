# 骑遇 · 浙江 4+2 骑行路线库

自驾带车，使用注明费用与条件的正式停车点，再换上自行车。原生静态HTML/CSS/JavaScript，无后端和运行时依赖，支持GitHub Pages项目路径。

目录更新：**2026-10-19**。当前目录有 **15条主线、32条道路方案、15个片区、4个城市组**（杭州、湖州、嘉兴含海宁、金华）。**16处去重停车片区**分为5处免费条件、6处收费参考、5处费用待确认；29家去重餐饮咖啡茶饮店，43处去重歇脚建议。长短方案、同一家店与同一停车点分别去重。

数量表示资料目录，不代表到访当天准入、收费、车位或营业已现场确认。逐条原文发布日期、读取日期、定位范围与缺口见页面及[data-notes.md](data-notes.md)。

## 运行与检查

```sh
python3 -m http.server 3000 --bind 127.0.0.1
node tests/catalog.test.cjs
```

当前30项Node测试已通过。Node检查覆盖统计去重、来源日期/费用分类、真实OSM边、单行与往返方向、道路累计里程、照明标记、湖岸多边形、图片许可及所有地图资源。

真实桌面/手机交互检查使用Node Playwright与已安装的Chrome/Chromium：

```sh
node tests/browser-check.cjs
# 兼容旧入口：python3 tests/browser-check.py
```

若Playwright位于其他安装目录，设置`NODE_PATH`；可通过`CHROME_EXECUTABLE_PATH`指定浏览器。脚本覆盖1440px与390px、所有方案地图与导航、级联筛选、照片弹窗、侧栏键盘滚动、PNG下载、收藏刷新与资源错误。前一轮通过Codex应用内浏览器实际操作完成了26方案UI验收，使用[响应式预览](tests/responsive-preview.html)中的真实1440px/390px嵌入视口，核对了全部26方案、筛选、弹窗、侧栏键盘滚动、地图下载和收藏刷新。验收记录和截图见[research/qa](research/qa)。本轮另实际验证4个新增夜骑方案、杭州夜间与滨江片区筛选、两家导航、咖啡定位及地图下载触发，详见qa/hangzhou-night-*。上述为10月16日历史验收；10月19日已独立运行Playwright，详见下方合并记录。手机App调起仍未真机测试。

重建本轮地图：

```sh
python3 scripts/build-verified-maps.py
node scripts/generate-maps.cjs
node scripts/export-maps.cjs
```

最后一步需要sharp（可用`NODE_PATH`指向已有运行时）。SVG与PNG采用网页同一渲染器。`build-regional-maps.py`为较早区域的独立生成器，不应为更新本轮线路而无故覆盖其输出。

## 数据与文件

按顺序加载：

```text
map-data → catalog → planning-data → regional-map-data → regional-catalog
→ huzhou-research → verified-map-data → verified-catalog → expanded-catalog
→ city-catalog → research-updates → night-catalog → photo-data
→ meiling-map-data → meiling-catalog → westlake-circuit-map-data → westlake-circuit-catalog
→ photo-updates → catalog-metadata
→ map-renderer → app
```

`expanded-catalog.js`为北山夜骑/夹浦/画溪；`city-catalog.js`为本轮南湖/金华/运河与迪荡研究图；`research-updates.js`维护缺口；`catalog-metadata.js`统一汇总城市与最终统计；`photo-data.js`关联照片，原始许可元数据在`research/photo-licenses.json`。night-catalog.js收录本轮杭州夜骑与两个新增研究方向。全部方案的SVG/PNG在`maps/`，道路配置及可重建快照在`research/`。

地图坐标WGS84，高德/百度坐标导航转GCJ-02。P为停车片区参考，S为实际道路节点；名称检索不等于入口实测，停车场内推行与探店绕行另计。橙线主线、绿色实际经过的OSM骑行道（可能行人共用）、紫C咖啡、红F餐厅、蓝R歇脚建议。无证据不宣称自行车独享或全天开放。
