## 证据与口径

- 路网来自13个2026-10-27取得的公开OSM map API小范围快照，源URL保存在快照source；`www.openstreetmap.org/api/0.6/map?bbox=...`本轮实际成功。保留way/node ID、几何、方向、通行标签和关系，移除贡献者账户资料。通过 `scripts/build-jiaxing-routes-20261027.py` 及 `scripts/lib/geometry.py` 只合并本批键。地图署名 © OpenStreetMap contributors / ODbL。
- 每条完整S→S路径按道路边累计，不画直线补洞，回程按实际有向路网求解；不重复翻倍。排除未标准入的footway/path/pedestrian/steps、service及隧道，尊重单行、条件通行和可读转向限制。生成器额外排除涉水及未确认可通过的gate类节点。
- 独立审查发现乌镇草稿误用4条`access=residents`居民限定路，累计约1.14km；已改经子夜路、乌塍线、工贸路公众道路绕行，最终13.5km。本批生成器加入公众准入白名单，专项检查已观察旧路线失败、修复后通过。停车泛名检索补入来源地址与交叉口，不只搜索县区加“停车场”。
- 王江泾原拟连接出现OSM节点12078055438 `ford=yes`，当前7.8km在该节点之前折返，未经过涉水点；没有把潜在涉水路当作桥梁。湘家荡、王江泾、新塍塘、大云、平湖及乍浦初稿的无意义支线已按实际连通重新选点，最终里程以上表为准。
- 鹃湖南岸实际经过OSM cycleway累计3.19km（去回合计），其余为道路接驳；按步骑共享说明，不宣称独享。其余12方案经过的cycleway为0，不能因为靠近绿道就画绿线或纳入专用道筛选。
- 秀湖内部5.32km、鹃湖完整外圈7.32km、完整新塍塘绿道、大云原10.46km等保留在各路线详情。秀湖与石臼漾旧研究记录原样迁入详情，不改旧核验日期。九龙山、南湾徒步线、湖心岛步道及西塘核心游览巷道没有纳入。

## 停车与补给

`pois.json`和`around.json`保存高德公开具名停车POI及实际查询参数；查询中远离目标区域的同名/模糊结果没有采用。13处均明确为道路停车位或路侧停车场，按用户2026-10-20既定规则默认免费，页面显著说明这是规划约定，实际收费、禁停、限时和取车条件优先，非运营方免费承诺。没有把景区免门票、限时免停或单位内部车位当作全天免费。

P/S坐标差14.9—107.9米，仅表示平台POI与公开道路起点的位置偏差，不是实测出入口道路距离；停车和道路起点分开标记。应在现场合法公共划线泊位停车，并从正式出口推行到S；车场内部推行、探店和景区步行支线另计。没有电话或现场核验。

`supplies.json`保存实际周边查询；首轮“餐厅”无结果的新塍塘，补搜“饭店”后取得具名店铺。26个新餐咖条目只作为到店参考，完整分店名/地址/坐标/POI ID在各线路中。均按需绕行显示，不把直线距离当店门通路，不承诺实时营业或实吃体验。24处道路片区歇脚建议不等于核实座椅、厕所、饮水或修车设施。

## 来源强度与检索边界

已读取浙江省体育局秀湖资料、浙江在线湘家荡绿道、看秀洲新塍塘报道、桐乡旅游旧路线、嘉兴日报桐乡凤凰湖资料、平湖住建绿道、平湖官方文旅线路、海盐发布City Ride、南北湖运营方2026山路公告，以及行者多条原详情。旧报道只说明历史方向；道路当前快照和通行边界另核，不承诺到访当天开放。

嘉善公共体育清单PDF及部分潮新闻旧页未能完整读取，未据搜索摘要认定具体路段准入；大云以实际可读行者路书和公共道路为依据。秀洲2026绿道报道原页404，保留为失败检索记录，不作为已读新证据。无电话、实骑或现场检查。

平湖星海揽月、乐屿千重、风塔拾光、稻浪逐风四个进阶骑行方向，本批没有取得完整取车闭环、逐段道路和跨沪范围，合并保存在一个独立研究入口，不展示免费P或正式里程。行者只核对实际可访问批次，Strava路段受登录限制，不能宣称穷尽当地所有平台。
