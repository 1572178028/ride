# 千岛湖100公里以上闭合环线 · 2026-10-30

## 接入范围与结论

用户要求再扩展一条100公里以上环千岛湖路线。本轮新增`qiandao-lake-loop`：顺时针绕中心湖区与西南湖区，完整157.0km，约9—12小时含短休与桥侧推行。不绕东北湖区，不宣称环遍千岛湖所有湖汊。它与已有上江埠短线共用南侧起步走廊，但新增淳杨西段、汾口和淳开北段等主体道路，构成新的独立地理主线，而非短线加长或反复绕圈。

- 渔港路道路起点—中心湖区码头外围—排岭半岛骑行桥—上江埠大桥南端—安阳—大墅—下姜村外围道路—汾口—浪川—姜家—界首—淳开线—集贤路道路接驳—千岛湖大桥桥侧推行—阳光路/县城绿道—渔港路取车。
- 实际道路累计156.9595km，显示157.0km；包含县城/乡镇道路接驳、下姜外围及旧路绕行、桥侧推行；不含停车位内部装卸、游园、餐咖探店支线。
- OSM `cycleway`累计30.23km，另有55.04km原标签`cycleway=lane`的道路；标线道不等于物理隔离或自行车独享。实际地图只把本线经过的`highway=cycleway`叠绿，G330接驳和推行不计入该覆盖。
- 集贤路连接1.58km为普通道路；千岛湖大桥桥侧及接驳1.43km仅下车推行，不进入该桥机动车主线。现场封闭、禁骑或不准携车时完整环线不成立，不能翻栏、逆行或改走大桥机动车主线。
- 现有68方案、48主线变为69方案、49主线，仍45浏览片区、50停车起点、5城市组；新增3家去重餐咖参考、5处道路歇脚建议，去重商户88、歇脚建议113。原68方案和旧几何保留。

版本号受当前维护入口“不改变版本号”的限制，保留V1.1.33，现有Release补充本轮代码更新，不移动原标签。开发分支对应保留版本命名；不把原计划1.1.34标为已发布。

## 停车、桥隧及道路核查

### 停车

[渔港路-道路停车位 B0H2GCVECD](https://www.amap.com/ssr/search/poi_detail?id=B0H2GCVECD)，渔港路与里联路交叉口西北120米，GCJ-02 `119.030121,29.598165`。本轮重新读取详情，分类路边停车场；原始响应保存在`parking.json`。沿用用户路侧默认规则：**路侧停车位默认免费，实际收费及禁停以现场标志为准**。这不是运营方免费公告，费用空白不当作免费证明；确认划线泊位、限时及取车窗口涵盖全部装卸、骑行、推行、休息。没有电话、现场或实骑核验。

百公里路线耗时长，不能用白天车位推断可过夜或连续两日免费；也不采用网上个人所述“交通运输局免费停车”替代已核具名道路泊位。

### 桥隧

- 上江埠大桥`251665217`为普通公路桥，公开环湖骑行资料、原道路属性及本轮高德骑行从北侧到南端的1.663km算路相互对照，见`bridge-ride.json`。不把上江埠机动车隧道当北侧绿道捷径；北侧实际走排岭半岛骑行桥及已识别绿道。
- 北侧淳开线采用原标签`cycleway=lane`的隧道路段：1368422056、395046579、395046580、395046582、532630802、532630805、532630807、532630808、395074023。OSM标线属性与公开千汾线骑游、穿隧道资料对应；只表述标线骑行道，不宣称各处均物理隔离。灯光、施工及当日禁行未实测，按现场指示，进隧道开前后灯。
- 下姜隧道、官山岭等本轮没有充分日常骑行道路属性的隧道不采用，以可连通普通旧路绕行；这是本线与常见136/140公里口径不同的原因之一。没有为凑里程人为重复大环。
- `528567576`为集贤路/G330道路连接，OSM类别trunk，没有motorroad=yes或bicycle=no；它与千岛湖大桥机动车桥面是不同way。不是把所有trunk道路放开，仅依据具体连接的属性和本轮1.574km骑行算路单独列入白名单，见`集贤路骑行接驳.json`；实际OSM行经1.5763km后经service 1570625742接入已标自行车绿道1570625739。此段按普通道路混行显示，现场管理优先，地图算路不等于现场保证。
- 桥侧1570625738、1570625737仍保留`footway=sidewalk`原标签，合计1.4342km，单独标`mode=push`；未改写为可骑，不算绿色骑行道。千岛湖大桥机动车桥面528567578仍明确排除。与旧东北方案“不进入G330主线”范围不同，新线只单独列出上述1.58km道路连接，不把旧线的结论外推。

完整路径为闭合环线，百度仅完整全程和关键点备用，不伪拆去返程。全程17点/备用11点，按真实道路已有节点取点，包含乡镇与桥侧关键节点；长距离点预算不能保证App重算精确贴合路网，必须对照本站桥隧说明。iPhone百度App内部重算未真机验证，安卓未扩测。
