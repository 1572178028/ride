## 已确定的产品规则

1. 相近同目的地用一个 `familyId` 入口，内部切换长短方案；每个方案保留自己的地图、停车、里程和适用照片。西湖、湘湖、翁金线已经归并。Apple Watch记录只作规划参考，不把运动截图直接当正式道路几何。
2. 允许收费停车，明确费用和条件；费用待确认与免费分别展示。地图明确分类的合法路侧泊位默认免费，记录 `user-default-roadside`，但现场收费、禁停、限时或专用规则优先；普通路肩空地不算泊位。浦阳江具名车场已获用户允许按“参考免费，费用及取车时间须入场确认”收录，归费用待确认。
3. 路网必须真实连通，遵守方向、准入和施工限制；不画直线补洞，不把商业地图规划复制成可自由使用的几何。地图WGS84，导航按已有转换生成GCJ-02。地图用短编号，点击看完整地点和导航。
4. 道路图优先小红书→抖音→bilibili→谷歌；尽量每方案3张。优先下载原图，失败再放大截纯图片区域，保留水印、作者、日期和出处；明确禁止转载的只留原帖链接。
5. 关联评分是人工证据评分，非定位概率：出处20、地点40、行程20、画面20；60–69浅绿、70–85中绿、>85深绿，可见标签只显示百分比。仅同片区无线索最高59，有明确地点冲突排除；评分不替代转载许可。只确认翁金线而不能细分路段的图，用户允许挂最长方案并注明不确定性；不是其他所有路线的自动豁免。
6. 扩展先拉 `codex/` 分支，验证后合并main。新增独立路线末位+1、新地级城市中间+1、新省份首位+1，各自累计、不清零。变体、补图、修正不加版本。新增正式主线须标签与GitHub Release；自动流程的 `contents:write` 已获授权。
7. 已授权常规提交、SSH推送和上线核查；不能把仅本地完成写成远程发布。任务中及时记进度，结束关闭自己开的后台检索页，保留用户原标签。不要改动或提交用户 `.idea/`。
